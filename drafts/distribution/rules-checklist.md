# Community rules checklist (drafts; nothing posted)

**SENDING AND POSTING ARE MARC GATES.** I may read public rules pages only. On 2026-10-24 most of them refused automated reads (HTTP 403) or could not be found, so almost no community's rules were actually read. That is stated per row; do not treat "not read" as "allowed".

## Before posting in any community

- [ ] Read the community's current rules page yourself, today. Note the date.
- [ ] Does it allow mentioning your own product at all? Is there a designated thread or day?
- [ ] Is the answer useful with the app link removed? If not, rewrite it.
- [ ] Is the disclosure line present and unshortened ("I'm the developer of ...")?
- [ ] Account history: does it already show ordinary participation, not only promotion? Reddit norm: roughly 90% participation and no more than about 10% self-promotion (a community convention, not a hard Reddit rule; subreddits set their own; source https://redship.io/blog/reddit-self-promotion-rules, read via search 2026-10-24, a marketing blog, not Reddit itself).
- [ ] No tracking parameters, no affiliate links, no claims about rival apps.
- [ ] If the rules are unclear, message the moderators and wait; do not post and apologise later.
- [ ] Record: date posted, URL, rule page read, outcome. Remove the post if a moderator asks.
