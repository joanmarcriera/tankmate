## How it was checked

CI (`.github/workflows/deploy.yml`) runs **no tests, lint or build**. It only rsyncs the repo to Hetzner on a push to `main`. So "as CI does" here means the deploy file set, which I computed from `git ls-tree` with the same excludes: `.git`, `.github`, `apple`, `*.md`. On top of that I ran:

- `node --test` (Node 22.23.4), as root and as a non-root `tester` user in a clean clone
- `node --check` on every JS file, plus a JSON parse of `manifest.webmanifest`
- each PR's own tests against **main's** source, to confirm the tests catch the defects they claim to
- `apple/scripts/prepare-web-bundle.py . <tmp>` (the iOS bundle)
- a test merge of all five PRs onto a local scratch branch from `origin/main`, with `node --test` after each conflict was resolved
- a Chromium (Playwright) upgrade test. Serve main (SW `tankmate-v2`), log a test, swap in the merged tree, reload. Then check that the stored history survives, which version is cached, the new behaviour, offline, and print.
